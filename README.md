# 🎨 OpenCV Color Detection Projects

A Computer Vision project built using **Python** and **OpenCV** that demonstrates real-time webcam access and color detection using the HSV (Hue, Saturation, Value) color space.

The project includes different programs for webcam testing, video capture, and detecting specific colors such as **Red**, **Blue**, **Green**, as well as detecting **all colors except white**.

---

## 📌 Features

- 📷 Webcam testing
- 🎥 Live video capture
- 🔴 Red color detection
- 🔵 Blue color detection with contour detection
- 🟢 Green color detection
- 🌈 Detect every color except white
- HSV color space conversion
- Real-time object masking
- Bounding box around detected objects (Blue detection)

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/OpenCV-Color-Detection-Projects.git
```

Move into the project directory

```bash
cd OpenCV-Color-Detection-Projects
```

Install dependencies

```bash
pip install opencv-python numpy
```

---

## ▶️ Run the Programs

### Test Webcam

```bash
python camera_test.py
```

### Capture Live Video

```bash
python CV1_capture_videos.py
```

### Detect Red Color

```bash
python CV2_red_color_detection.py
```

### Detect Blue Color

```bash
python CV3_blue_color_detection.py
```

### Detect Green Color

```bash
python CV4_green_color_mask.py
```

### Detect Every Color Except White

